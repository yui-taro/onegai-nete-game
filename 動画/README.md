# 動画

## プレイ動画（通し・音あり）

**▶ [OnegaiNete_playthrough.mp4 をダウンロード](https://github.com/yui-taro/onegai-nete-game/releases/download/v0.1.0/OnegaiNete_playthrough.mp4)**（285MB / 2分42秒）

眠った赤ちゃんをベッドへ下ろすまでの通しプレイです。音声が入っているので、
**寝息・ぐずり声を聞きながら見てください。** 赤ちゃんの状態を読むための手がかりの多くは音にあります。

途中で一度失敗し（急な動きで起こしてしまう）、やり直して成功するところまで入っています。

### 見どころ

| 場面 | 何を見るか |
|---|---|
| 揺らして寝かしつける | 速すぎても遅すぎても寝ない。表情と呼吸が手がかり |
| ベッドへ下ろす | 近づくほど覚醒しやすくなる。止まって待つのも有効 |
| 失敗 | 急な動きで起きてしまう。泣き出すまでの「戻せる間」がある |
| 腕を抜く | 支えを片方ずつ抜く。抜いては止める |
| 後ずさり | ここまで来ても、まだ起きる |
