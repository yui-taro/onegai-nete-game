# 動画

## プレイ動画（通し・音あり）

**▶ [おねがい寝て_プレイ動画.mp4](おねがい寝て_プレイ動画.mp4)**（51MB / 2分42秒 / 720p）

上のリンクを開くと**GitHubの画面でそのまま再生できます**。ダウンロードは不要です。

眠った赤ちゃんをベッドへ下ろすまでの通しプレイです。音声が入っているので、
**音を出して見てください。** 赤ちゃんの状態を読む手がかりの多くは、寝息とぐずり声にあります。

途中で一度失敗し（急な動きで起こしてしまう）、やり直して成功するところまで入っています。

### 見どころ

| 場面 | 何を見るか |
|---|---|
| 揺らして寝かしつける | 速すぎても遅すぎても寝ない。表情と呼吸が手がかり |
| ベッドへ下ろす | 近づくほど覚醒しやすくなる。止まって待つのも有効 |
| 失敗 | 急な動きで起きてしまう。泣き出すまでの「まだ戻せる間」がある |
| 腕を抜く | 支えを片方ずつ抜く。抜いては止める |
| 後ずさり | ここまで来ても、まだ起きる |
